Tipos de Requisitos

A análise classifica os Requisitos para definir as expectativas do sistema de forma estruturada:

Categoria O que define? Exemplo
Requisitos Funcionais (RF) Comportamentos e funcionalidades diretas do sistema. "O sistema deve emitir um relatório PDF das vendas mensais."
Requisitos Não-Funcionais (RNF) Qualidades, restrições e critérios de desempenho. "O tempo de resposta do checkout não deve ultrapassar 2 segundos."
Regras de Negócio (RN) Políticas e diretrizes operacionais do cliente/empresa. "Descontos superiores a 15% exigem aprovação do gerente."
